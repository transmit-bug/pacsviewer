# PACS Viewer 医生使用手册（1.0 试点）

面向眼科医生与技师的日常操作速查。系统入口：`https://<服务器地址>`。

## 1. 登录

1. 浏览器打开系统地址，输入用户名和密码登录。
2. **首次登录**：使用管理员下发的初始密码登录后，页面会先要求**强制修改密码**（新密码至少 8 位，且须同时包含字母和数字）。改密完成后重新进入系统。
3. **会话超时**：
   - 空闲 **30 分钟**后自动登出，需重新登录；
   - 即使持续操作，自登录起 **12 小时**后也会强制重新登录（安全策略）。
   - 系统没有「记住密码」，请妥善保管凭据；连续 5 次输错密码将锁定 15 分钟。

## 2. 登记患者 → 建检查 → 上传图像

### 2.1 登记患者

「患者列表」→「新建患者」，填写姓名、性别、出生日期、联系方式等必填项后保存。患者可打标签（如糖尿病视网膜病变、青光眼）便于筛检随访。

### 2.2 创建检查

在患者详情页 →「新建检查」：

- 选择**检查模态**（OCT / 眼底彩照 / FFA / ICGA / OCTA / 视野等）、检查日期（默认今天）、检查描述与设备；
- 保存后进入检查详情，即可上传图像。

### 2.3 上传图像

支持两种方式：点击选择文件，或**直接把整个文件夹拖入上传区**（文件夹会被递归读取）。

| 规则 | 说明 |
|---|---|
| 支持格式 | `.dcm` `.dicom` `.jpg` `.jpeg` `.png` `.bmp` `.tiff` `.tif` |
| 单文件上限 | **100 MB**，超限文件自动剔除并提示 |
| 单批数量 | 最多 **200 个文件**/批（OCT 序列常见超过百帧，故放宽到 200） |
| DICOMDIR | 不支持，选中时会有明确提示，请直接拖入影像文件 |
| 失败处理 | 批量上传时单个失败文件**不会中断整批**，其余继续；结束后提示失败数，可点「重试失败」仅重传失败文件 |
| 多文件落位 | 同批文件自动归入同一序列 |

> **DICOM 归因说明**：上传 `.dcm/.dicom` 文件时，系统按**文件内部的 DICOM 标签**（患者姓名/ID、检查与序列号）自动匹配或新建患者、检查和序列记录——即使您已在界面上选了目标患者。如需归入已登记患者，请确保设备端 DICOM 标签信息准确。

## 3. 阅片基础

从检查列表或患者详情打开阅片器。

### 3.1 工具

- **导航类**：平移、缩放、窗宽窗位调节（OCT 有预设窗位可一键切换）；
- **变换类**：旋转 90°、水平/垂直翻转、适配窗口；
- **标注/测量类**：长度、角度、探针取值、箭头/自由手标注；标注按图层管理，可显隐；
- **多帧浏览**：OCT 容积扫描用 Cine 播放器逐帧/滚动浏览；FFA 时序图像按造影时间点导航。

### 3.2 键盘快捷键

输入框获得焦点时快捷键不生效。按 `?` 可随时呼出帮助面板。

| 键 | 功能 |
|---|---|
| `1`–`8` | 切换工具：1 平移 / 2 缩放 / 3 窗宽窗位 / 4 长度 / 5 角度 / 6 探针 / 7 标注 / 8 自由手 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适配窗口 |
| `R` / `Shift+R` | 顺时针 / 逆时针旋转 90° |
| `H` / `V` | 水平 / 垂直翻转 |
| `←→↑↓` | 上一张 / 下一张图像 |
| `Delete`/`Backspace` | 删除选中标注 |
| `Ctrl/Cmd+Z`（+Shift） | 撤销 / 重做 |
| `Ctrl/Cmd+E` | 开关编辑工作区（图层/滤镜/测量面板） |
| `?` | 快捷键帮助 |

## 4. 报告

### 4.1 创建与编辑

在检查详情或报告页基于**报告模板**（OCT 报告、眼底彩照报告、FFA、视野、OCTA、综合报告等）创建报告；结构化字段（诊断、测量值、所见、印象等）按模板定义填写。每次状态变更都会保存一个版本快照，可追溯历史。

### 4.2 状态流转

```
draft（草稿）──提交审核──▶ pending_review ──审核通过──▶ reviewed ──发布──▶ published
                              │                                      
                              └───── 驳回 ──── 回到 draft ◀──────────┘（驳回路径）
```

- 草稿完成 → 点**提交审核**；
- 具有审核权限的角色（默认为管理员）对 pending_review 的报告执行**审核通过**或**驳回**（驳回需填意见，退回草稿）；
- reviewed 状态的报告由有权限者**发布**，发布后对外可见并记录发布时间；
- 已发布的报告可通过打印导出 PDF。

## 5. 随访对比

「对比」页（/compare）用于同一患者的随访比较：

1. 选择患者，分别指定**基线检查**与**对比（本次随访）检查**；
2. 双栏对照浏览两幅图像，可叠加显示两次的标注；
3. 系统自动汇总两次的测量指标差值（如 RNFL、黄斑厚度变化）；
4. 确认后点**保存随访记录**，生成带差值表的随访档案，供趋势追踪。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 操作中途被登出 | 空闲超 30 分钟所致，重新登录即可；未保存的草稿内容需重新填写 |
| 上传的 DICOM 图像归到了别的患者名下 | 设备端 DICOM 标签（患者姓名/ID）与登记信息不一致；联系管理员修正归属后，校正设备端标签 |
| 部分文件上传失败 | 查看 toast 提示中的失败原因（超限/格式不支持），点「重试失败」重传 |
| 找不到某次检查 | 用全局搜索（`Ctrl/Cmd+K`）或患者列表按姓名/病历号/拼音检索 |
